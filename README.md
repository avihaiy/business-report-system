# 🏛️ מערכת ביקורת עסקים עירונית (Business Audit & Inspection System)

מערכת דיגיטלית מתקדמת לניהול, תזמון ודיווח של ביקורות ופיקוח על עסקים עירוניים. המערכת כוללת ממשק ניהול רחב (Admin Dashboard) לצד ממשק מותאם אישית למפקחים בשטח (Inspector Interface).

המערכת פותחה כרכיב React עצמאי ומודרני (Single Page Application) עם דגש על רספונסיביות מלאה למובייל, חוויית משתמש יוקרתית (Premium Glassmorphism), ומערכת התראות דו-כיוונית דינמית.

---

## 🚀 תכונות עיקריות (Core Features)

### 📱 התאמה מלאה למובייל (Mobile Responsive FIRST)
* **עיצוב תפריט המבורגר (Hamburger Drawer)**: במובייל סרגל הניווט הופך למגירה נשלפת מצד ימין (RTL) עם אפקט טשטוש רקע מרהיב.
* **גריד דינמי**: כל הסטטיסטיקות, הגרפים והטבלאות מסתדרים אוטומטית אנכית למניעת גלילה אופקית.
* **ממשק מגע מותאם**: מקלדות נוחות, כפתורים רחבים ופינות מעוגלות מרווחות.

### ✨ עיצוב פרימיום מודרני (Design & Aesthetics)
* **אפקט זכוכית (Glassmorphic Cards)**: שימוש בטכנולוגיית `backdrop-filter` המעניקה למערכת מראה יוקרתי, שקוף ונקי.
* **רקע גרדיאנט דינמי**: שילוב מעברי צבעים רכים בגווני כחול כהה וסגול מעורפלים.
* **מיקרו-אנימציות**: כפתורים וכרטיסים פועמים ומוארים בריחוף (`pulse-glow` ו-`hover transform`).

### 🔔 מערכת התראות ומשימות חכמה (Smart Notifications & Tasks)
* **התראות שצריך לעשות דיווח**:
  * פונקציה חכמה המנתחת בזמן אמת אילו עסקים דורשים ביקורת מיידית (עסקים ללא היסטוריית דיווחים, עסקים שלא בוקרו ב-30 הימים האחרונים, או מעקבים שהגיע מועדם).
  * באנר פועם בצבע אדום בדשבורד המתריע על משימות דחופות פתוחות.
  * אפשרות למפקח לדווח על ביקורת חדשה **ישירות מתוך ההתראה** בלחיצת כפתור אחת.
* **התראות שמתקבל דיווח**:
  * בכל פעם שמפקח מזין ביקורת, נוצרת התראת מערכת אוטומטית למנהלים עם הציון שניתן וחיווי צבעים (אדום לציון נמוך/סיכון גבוה, ירוק לציון מושלם).

## 🛠️ טכנולוגיות (Tech Stack)
* **Core**: React (Hooks, state, memo, callback)
* **Visuals**: CSS-in-JS (Inline dynamic styling) & Custom HTML5 Style injection
* **Charts**: Recharts (Responsive lines, pies, bars, and radar charts)
* **Database**: LocalStorage wrapper (סנכרון נתונים מקומי מלא עם אפשרות איפוס)

---

## 🔧 התקנה והרצה (Setup & Execution)
מכיוון שהמערכת בנויה כקובץ React עצמאי (`business-report-system.jsx`), ניתן להטמיע אותה בקלות בכל פרויקט React קיים (Vite, Next.js, create-react-app).

1. העתק את הקובץ לתיקיית הרכיבים (`components` או `pages`) בפרויקט שלך.
2. ודא כי הספריות הבאות מותקנות בפרויקט:
   ```bash
   npm install recharts
   ```
3. יבא והרץ את הרכיב:
   ```javascript
   import App from './business-report-system';
   ```
